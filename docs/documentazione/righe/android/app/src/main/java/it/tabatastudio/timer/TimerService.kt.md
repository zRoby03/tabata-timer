# android/app/src/main/java/it/tabatastudio/timer/TimerService.kt

Servizio Android in primo piano per background e schermo spento.

Mantiene CPU e notifica durante il lavoro, aggiorna i controlli e rilascia le risorse. Non apre una sessione audio che interrompa Spotify o YouTube.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
