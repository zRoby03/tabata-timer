# android/app/src/main/java/it/tabatastudio/data/Database.kt

Persistenza Room/SQLite e repository transazionale.

Workout, sessioni, checkpoint e impostazioni sono tabelle distinte. Mutex e transazioni impediscono sostituzioni parziali e duplicazione del risultato.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
