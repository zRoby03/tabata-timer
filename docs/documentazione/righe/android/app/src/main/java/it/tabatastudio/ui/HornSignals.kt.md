# android/app/src/main/java/it/tabatastudio/ui/HornSignals.kt

Riproduzione nativa dei nove WAV locali.

SoundPool usa il volume multimediale senza richiedere focus audio. Una sola voce alla volta impedisce sovrapposizioni.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
