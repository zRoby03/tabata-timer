# android/app/src/main/java/it/tabatastudio/timer/TimerRuntime.kt

Proprietario del motore Android per l’intero processo.

Coordina avvio del servizio, controlli, checkpoint, risultato unico e audio. Solo il servizio avanza il timer e scrive i checkpoint.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
