# .gitattributes

Dato o configurazione di progetto: .gitattributes.

Il file è mantenuto nel repository per rendere riproducibile la consegna; non contiene salvataggi personali.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
