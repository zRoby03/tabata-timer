# tools/documentation/javascript.mjs

Strumento di generazione della documentazione.

Lavora su Git e sui token dei sorgenti, senza eseguire l’app o pubblicare il sito. Il suo codice è spiegato nel documento affiancato.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
