# scripts/generate-horn.py

Generazione locale dei segnali WAV.

Usa PCM mono deterministico; il fischio meno acuto dura 500 ms, il conto alla rovescia contiene note brevi distinte.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
