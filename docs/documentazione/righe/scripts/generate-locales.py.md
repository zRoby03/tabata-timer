# scripts/generate-locales.py

Generatore del catalogo web e delle risorse Android.

Verifica i segnaposto, genera ID stabili e scrive tutte le lingue senza servizi esterni di traduzione.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
