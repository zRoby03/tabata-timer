# scripts/package-cloudflare.py

Preparazione dello ZIP statico Cloudflare Pages.

Include soltanto web e _headers, verifica ogni byte e i limiti del servizio; non distribuisce APK, credenziali o dati personali.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
