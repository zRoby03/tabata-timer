# scripts/render-brand-icons.mjs

Rasterizzazione delle icone web installabili.

Playwright renderizza il vettore in PNG 192 e 512; è uno strumento di sviluppo, non una dipendenza del sito.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
