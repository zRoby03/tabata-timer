# web/sw.js

Service worker per la cache offline dei soli file statici.

Non memorizza backup personali né risposte di terze parti. Le pagine Cloudflare senza estensione vengono associate alla copia HTML corretta.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
