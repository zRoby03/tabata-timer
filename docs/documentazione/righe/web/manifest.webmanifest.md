# web/manifest.webmanifest

Manifest di installazione della web app.

Nome, percorso iniziale e icone permettono l’installazione PWA; non aggiungono i privilegi del servizio Android.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
