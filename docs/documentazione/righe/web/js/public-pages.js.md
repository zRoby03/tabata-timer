# web/js/public-pages.js

Lingua e aspetto delle pagine pubbliche Informazioni/Privacy.

Mostra una sola versione linguistica, ricorda la scelta e riusa tema e palette senza avviare il timer.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
