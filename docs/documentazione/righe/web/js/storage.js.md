# web/js/storage.js

Repository browser con modalità temporanea e persistente.

Le scritture locali sono esplicite; errori di quota o dati corrotti non cancellano indiscriminatamente l’archivio.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
