# web/js/i18n.js

Localizzazione browser e scelta della lingua.

Usa il catalogo italiano/inglese/spagnolo, conserva la preferenza locale e preserva i nomi utente nei segnaposto.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
