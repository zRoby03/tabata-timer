# web/js/timer.js

Motore web e segnali Web Audio.

Il tempo trascorso deriva da performance.now(), non dal numero di chiamate di setInterval. Audio e screen wake lock sono responsabilità separate dal conteggio.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
