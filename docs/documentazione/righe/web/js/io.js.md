# web/js/io.js

Importazione, esportazione JSON e CSV sul web.

Controlla formato, versione, date, ID, metriche e limite di 5 MiB; il CSV neutralizza celle interpretabili come formule.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
