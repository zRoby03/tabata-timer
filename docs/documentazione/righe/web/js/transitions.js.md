# web/js/transitions.js

Segnali di cambio fase e relativi guadagni.

Fischio all’inizio del lavoro, sospiro all’inizio del recupero e campanella prima del defaticamento o alla fine.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
