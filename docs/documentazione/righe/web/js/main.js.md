# web/js/main.js

Controller dell’applicazione web.

Collega navigazione, moduli, repository, timer e segnali. Le scelte dell’utente diventano mutazioni del modello o richieste esplicite di salvataggio.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
