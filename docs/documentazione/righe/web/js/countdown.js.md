# web/js/countdown.js

Rilevazione delle tre note del conto alla rovescia.

Ogni visita a una fase emette una nota per secondo sul 3, 2, 1; ritardi e pause non producono raffiche di note arretrate.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
