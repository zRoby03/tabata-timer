# web/js/timeline.js

Compilazione del programma in fasi elementari.

Secondi e minuti dell’interfaccia diventano durate in millisecondi; ogni pausa viene inserita soltanto tra elementi consecutivi.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
