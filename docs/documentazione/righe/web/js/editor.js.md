# web/js/editor.js

Editor web dei programmi personalizzati.

Produce HTML con valori escapati e un’anteprima ricavata dalla timeline; la modifica del modello avviene nel controller.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
