# locales/messages.json

Catalogo editoriale delle tre lingue.

Ogni chiave è il testo italiano sorgente; l’array contiene inglese, spagnolo ed eventualmente una variante italiana esplicita.
I numeri si riferiscono al sorgente originale; il collegamento apre esattamente quella riga. I commenti DOC nel branch sono aggiunte didattiche.
